The agent pipeline

I work heavily with Claude Code, and I write the skills and hooks that make it useful on a 4,700-file Unity project. The /ship protocol reviews the branch, proves any editor tool’s output landed, finishes the docs, makes a go/no-go call, then opens the PR, in three lanes: /ship-quick, /ship-deep and /ship-tools. 1,952 commits from Claude Code sessions I directed landed through my pull requests.
