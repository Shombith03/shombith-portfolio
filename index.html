Amoebius

My engine: a .NET 10 engine that runs Cosmic Shore without Unity. Started June 2026, it is 15 projects under Port/ in the game’s repo.

Owned

Runs the real game

The actual Assets/_Scripts compile against engine-side API surfaces with zero errors. The launcher fetches a branch, compiles it, runs it, and builds Android and iOS.

6a4ace506 8fddab744

Runtime

Engine runtime

A scene graph with reflective lifecycle discovery, a deterministic GameLoop, GameTask in place of UniTask, an injection container in place of Reflex, and a SOAP layer in place of Obvious.Soap.

Network

Cross-process networking

TCP transport, RPC routing and a session directory, carrying Netcode’s own model between processes.

Tooling

The systems that keep the work moving.

Owned

Froglet Compute

An automated compute server on a VM. It takes job requests through git, runs them, and writes each job’s best result and a heartbeat back to the repo. It drives per-vessel tuning runs, a bioform forge and Unity training.

Owned

cs-asset

Edits Unity scenes and prefabs and writes them back byte for byte, with no Unity involved. Verified across 2,030 files.

Owned

The agent pipeline

I work heavily with Claude Code, and I write the skills and hooks that make it useful on a 4,700-file Unity project. The /ship protocol reviews the branch, proves any editor tool’s output landed, finishes the docs, makes a go/no-go call, then opens the PR, in three lanes: /ship-quick, /ship-deep and /ship-tools. 1,952 commits from Claude Code sessions I directed landed through my pull requests. Directing that well is its own skill.
