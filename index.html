Amoebius

A .NET 10 engine I’m writing that compiles and runs Cosmic Shore without Unity. Started June 2026; 15 projects under Port/ in the game’s repo.

Owned

Running Cosmic Shore

The game’s own Assets/_Scripts compile against the engine’s API surfaces with zero errors. The launcher fetches a branch, compiles it, runs it, and builds Android and iOS.

6a4ace506 8fddab744

Engine

Runtime

A scene graph with reflective lifecycle discovery, a deterministic GameLoop, GameTask in place of UniTask, an injection container in place of Reflex, and a SOAP layer in place of Obvious.Soap.

Engine

Networking

TCP transport, RPC routing and a session directory, carrying Netcode’s model between processes.

aeba7a882

Engine

Online play

Uses the same UGS Lobby and Relay as the Unity build.

01f582228

Engine

Rendering

Matches the Unity build’s rendering, including a reimplementation of URP 17.3’s Gaussian bloom.

fa16d6115

Engine

MCP server

Lets an agent build the game, start it, take screenshots, click and steer, and read live values.

Engine

Capture

The loop is deterministic, so the engine doubles as a render environment for the game’s trailers and marketing footage: repeatable runs instead of hand-flown takes.

Tooling

Tools I built for the project and the team.

Owned

Froglet Compute

A compute server on a VM. It takes job requests through git, runs them, and writes each job’s best result and a heartbeat back to the repo. It runs per-vessel tuning, a bioform forge and Unity training jobs.

Owned

cs-asset

Edits Unity scenes and prefabs and writes them back byte for byte, without Unity. Checked against 2,030 files.

Agents

/ship

A release protocol for agent work: review the branch, prove any editor tool’s output landed, finish the docs, make a go/no-go call, then open the PR. Three lanes: /ship-quick, /ship-deep and /ship-tools.
